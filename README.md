# PSE Vorkurs – Tag 1

Repository für die Programmieraufgaben des ersten Tages im Vorkurs für Programmierung und Softwareentwicklung (PSE) an der Universität Stuttgart.

---

## Übersicht & Aufgaben

| Aufgabe | Thema | Beschreibung |
| :--- | :--- | :--- |
| **Aufgabe 1** | Grundlagen & Variablen | Konsolenausgaben, ASCII-Art, einfache Arithmetik (`int`, `String`). |
| **Aufgabe 2** | `Scanner` & Eingaben | Dynamische Eingaben verarbeiten, Typkonvertierung mit `Integer.parseInt()`. |
| **Aufgabe 3** | Verzweigungen (`if-else`) | Boole'sche Ausdrücke, Einlasskontrollen und Logik-Abfragen. |
| **Aufgabe 4** | Zufall & Modulo | Schere, Stein, Papier (inkl. Echse & Spock Erweiterung) mit `java.util.Random` und Modulo-Logik. |

---

## Verwendung

1. Repository klonen oder als ZIP herunterladen.
2. Sicherstellen, dass ein aktuelles Java Development Kit (JDK) installiert ist.
3. Die gewünschte `.java`-Datei in einer IDE (z. B. IntelliJ IDEA oder VS Code) öffnen oder direkt über das Terminal kompilieren und ausführen:

```bash
javac Dateiname.java
java Dateiname
